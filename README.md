# 🧠 Neural Network: Layered Perceptron System for Unreal Engine

**The power of machine learning — now inside your game.**

Bring your AI to life with a dynamic, fully programmable multilayer perceptron system designed for Unreal Engine. Whether you're building intelligent NPCs, evolving agents, or experimenting with neural evolution — this plugin is your sandbox. Easy to integrate, fully customizable, and ready to train, mutate, and evolve on the fly.

This repo **doesn't** include plugin. Check plugin in [marketplace](https://www.fab.com/listings/f4bc4f7b-4cf9-4c64-8d47-4a7730dd283a)
---

## ✨ Features

- 🧮 Forward & backward propagation (Backpropagation algorithm)  
- 🎯 Real-time training with customizable learning rate  
- 🧩 Multiple activation functions: `Sigmoid`, `ReLU`, `Tanh`, `Linear`  
- 🧬 Mutation strategies: `Shuffle`, `Reweight`, `Shift`, `Multiply`, `Increment`  
- 🧪 Genetic crossover: `Average` and `Weighted` methods  
- 💾 Save/load full network configuration using `FNeuralNetworkData`  
- 🔧 Fully Blueprint-compatible
